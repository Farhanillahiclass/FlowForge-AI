## Install
1. Download `13-youtube-publishing-assistant.json` and import it into your n8n instance.
2. Open the dedicated guide linked above and follow its credential/setup steps.
3. Replace placeholder values and connect every unfinished integration node.
4. Test with synthetic data before activating.

## Credential safety
Create credentials in n8n Credentials. Never commit tokens, passwords, client data or private keys to GitHub.

## Validation status
This README organizes the workflow's documentation; it is not proof of a live execution test. Confirm all nodes, credentials, success paths, error paths and duplicate handling in your own n8n instance before production use.
